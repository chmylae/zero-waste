# Zero Waste AI 3.0

Сайт для чистых городов Казахстана: жители сообщают о свалках с фото, место появляется на карте, администраторы рассматривают обращения и меняют статус. Для предприятий в личном кабинете остались все разделы версии 2.1.

## Что внутри

| Страница | Адрес | Кто видит |
|---|---|---|
| Главная | `/` | все |
| Карта загрязнений (OpenStreetMap, фото на метках) | `/map` | все |
| Вход | `/login` | все, администраторы входят здесь же |
| Регистрация | `/register` | все |
| Сообщить о мусоре | `/report` | после входа |
| Личный кабинет | `/cabinet` | после входа |
| Админ-панель | `/admin` | только роль «администратор» |
| Прежний центр управления 2.1 | `/classic` | предприятия и администраторы |

**Роли и ограничения**

- **Житель.** Отправляет обращения (не больше 10 в сутки), видит их статус, историю и ответ администратора, может отозвать обращение, пока оно «Новое». Меняет профиль и пароль.
- **Предприятие.** Всё то же, плюс обзор, сканер, анализатор, журнал отходов, прогноз, рекомендации, эко-помощник, EcoScore, пункты переработки, аналитика, калькулятор и отчёты CSV/Excel. Житель может стать предприятием в профиле.
- **Администратор.** Видит всё и в админ-панели:
  - графики;
  - все обращения с фото и автором;
  - смена статуса (отказ только с указанием причины) и комментарии;
  - удаление и выгрузка CSV;
  - список пользователей: можно назначить администратора или заблокировать пользователя.

**Проверки при регистрации:**
- имя: 2–60 букв, без цифр;
- корректный email, не занятый другим аккаунтом;
- для предприятия обязательно название компании (2–80 символов);
- город только из списка, телефон проверяется по формату;
- пароль 8–64 символа, буквы и цифры, без части email, повтор пароля должен совпадать;
- обязательно согласие с правилами;
- скрытое поле против ботов, не больше 5 регистраций в час с одного IP.

**Защита:**
- вход блокируется на 15 минут после 5 ошибок;
- заблокированный пользователь не может войти;
- CSRF-токен на всех формах и в API;
- пароли хранятся в виде хэша;
- фото проверяются и пересохраняются через Pillow, поэтому из файла удаляются EXIF и GPS;
- в описании обращения нельзя указать телефон;
- точка на карте должна быть в пределах Казахстана.

## Запуск на Windows

Двойной щелчок по `run.bat` или вручную:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000

`run_public.bat` открывает сайт другим устройствам в той же Wi‑Fi сети: http://IP-вашего-ПК:8000.

## Аккаунты

| Роль | Email | Пароль |
|---|---|---|
| Администратор | `admin@zerowaste.kz` | `ZeroWaste2026!` |
| Предприятие (демо) | `demo@zerowaste.ai` | `demo1234` |

После первого входа администратора **сразу смените пароль** (Кабинет → Профиль и безопасность). На сервере задайте свои данные через переменные `ZERO_WASTE_ADMIN_EMAIL` и `ZERO_WASTE_ADMIN_PASSWORD` до первого запуска.

Дать права администратора зарегистрированному пользователю:

```powershell
python app.py make-admin user@mail.kz
```

или в админ-панели в таблице «Пользователи».

## Как выложить в интернет (чтобы сайт открывали все)

**PythonAnywhere (бесплатно, база и фото сохраняются)**
1. Зарегистрируйтесь на pythonanywhere.com и загрузите zip во вкладке Files, распакуйте командой `unzip` в Bash-консоли.
2. В консоли: `cd zero_waste_ai && pip install --user -r requirements.txt`.
3. Web → Add a new web app → Manual configuration (Python 3.11). В WSGI-файле оставьте:
   ```python
   import sys; sys.path.insert(0, '/home/ВАШ_ЛОГИН/zero_waste_ai')
   from app import app as application
   ```
4. Там же в Static files: URL `/static/` → `/home/ВАШ_ЛОГИН/zero_waste_ai/static`. Нажмите Reload. Сайт будет по адресу `ВАШ_ЛОГИН.pythonanywhere.com`.

**Render.com.** В проекте уже есть `render.yaml` и `Procfile`. Загрузите папку в GitHub и создайте Blueprint. На бесплатном тарифе диск временный: база и фото сбрасываются при каждом перезапуске, поэтому для постоянной работы нужен платный диск или PythonAnywhere.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `ZERO_WASTE_SECRET` | ключ сессий (иначе создаётся файл `.secret_key`) |
| `ZERO_WASTE_ADMIN_EMAIL`, `ZERO_WASTE_ADMIN_PASSWORD` | первый администратор |
| `ZERO_WASTE_HTTPS=1` | cookie только по HTTPS (включите на хостинге) |
| `ZERO_WASTE_REPORTS_PER_DAY` | лимит обращений в сутки (по умолчанию 10) |
| `ZERO_WASTE_DB` | путь к файлу SQLite |

## Честно о возможностях

- Анализ фото работает на правилах: состав, опасность и объём считаются по выбранным типам мусора, объёму и описанию. Обученной модели компьютерного зрения нет.
- Сайт не отправляет обращение в акимат сам. Он даёт готовый текст, номера 109, 1414, 112 и ссылку на eOtinish.
- Старая база `zero_waste.db` подходит: при запуске таблицы обновятся автоматически. Перед обновлением сделайте копию.
